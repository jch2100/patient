공개 자료로만 연습합니다

  • 실제 민원, 개인정보, 계약서, 감사·소송 자료, 미공개 특허정보를 넣지 않습니다.
  • 내부 URL, 계정 정보, 비밀번호, 인증정보를 복사하지 않습니다.
  • 공개 보도자료, 공개 특허정보, 가상 회의록처럼 안전한 자료로 연습합니다.
  • AI의 답은 초안입니다. 숫자·사실·출처·최종 판단은 사람이 확인합니다.

검색과 AI의 역할

구분 검색 생성형 AI
잘하는 일 원문·공식 페이지 찾기 여러 자료 요약·비교·구조화
결과 모양 링크와 문서 설명·표·초안
주의점 검색어에 따라 빠뜨릴 수 있음 그럴듯한 오류를 만들 수 있음
사람의 역할 적절한 원문 선택 근거 대조와 최종 판단

둘 중 하나를 고르는 문제가 아닙니다. 검색으로 근거를 찾고, AI로 일을 이어가고, 다시 원문으로 확인하는 것이 기본 흐름입니다.

AI가 틀리는 세 순간

  1. 자료가 없을 때 — 빈칸을 추정으로 채웁니다.
  2. 질문이 넓을 때 — 여러 기준을 섞어 두루뭉술하게 답합니다.
  3. 최신성이 중요할 때 — 오래된 정보와 현재 정보를 구분하지 못할 수 있습니다.

🔎 검증 문장

답변이 매끄럽다는 것과 사실이 맞다는 것은 별개입니다. 특히 날짜, 수치, 기관명, 법령, 특허 상태는 원문을 다시 확인합니다.

4. 결과 표의 열은 "확인할 질문 / 필요한 근거 / 추천 출처 / 확인 상태"로 하세요.

답을 받은 뒤 확인할 것

  • 출처 없이 숫자나 날짜를 단정하지 않았는가?

  • 사실, 해석, 제안을 구분했는가?
  • 모르는 것은 확인 필요로 남겼는가?

막힐 때

인터넷 검색 기능이 없는 AI라면 먼저 검색에서 공식 문서를 찾고, 필요한 부분만 복사해 AI에게 제공합니다. 문서 전체가 비공개라면 올리지 말고 공개 가능한 요약문이나 가상 자료로 바꿉니다.

PRACTICE · PUBLIC PATENT DATA약 2분

특허 검색 결과는 목록이 아니라, 검증해야 할 표본입니다

AI가 검색 결과를 정리해도 검색식·대상·상태·노이즈는 사람이 확인해야 합니다. 특허정보 업무에서는 이 검증 과정 자체가 전문성입니다.

이 장의 목차

  1. KIPRIS와 KIPRIS Plus를 쉽게 구분하면
  2. 검색 결과에서 확인할 네 가지
  3. 표본 검증 실습
  4. 검증자의 체크리스트

KIPRIS와 KIPRIS Plus를 쉽게 구분하면

  • KIPRIS는 사람이 화면에서 국내외 지식재산 정보를 검색하고 원문을 확인하는 서비스입니다.
  • KIPRIS Plus는 특허정보를 Open API와 벌크데이터 방식으로 활용할 수 있게 제공합니다.
  • 오늘 학습자는 공개 검색 결과를 검증하고, 강사는 마지막에 AI가 검색 도구를 호출하는 모습을 시연합니다.

KIPRIS Plus 공식 안내에 따르면 특허정보는 Open API와 벌크데이터 방식으로 활용할 수 있습니다. 강사 시연은 공개 가능한 데이터만 사용하며 인증정보는 화면과 교재에 표시하지 않습니다.

법령 MCP 설치 — API 키 없이 연결하기

법령 MCP는 AI가 법령·판례·조례를 조회하도록 연결하는 도구입니다. 이번 학습자 경로는 공개 원격 서버의 기본 주소만 등록하며, API 키·비밀번호를 입력하지 않습니다.

  1. ChatGPT에서 설정의 앱/커넥터 또는 고급 설정 메뉴를 엽니다. 계정·요금제·조직 정책에 따라 메뉴 이름과 위치가 다를 수 있습니다.

  2. 허용되어 있다면 Developer mode 또는 사용자 지정 MCP 커넥터 생성을 켭니다. 메뉴가 보이지 않으면 강사 시연으로 전환하고 관리자에게 정책을 확인합니다.

  3. Add connector 또는 Create connector를 선택합니다.

  4. 이름에 법령 MCP를 입력합니다.

  5. 서버 주소에 아래 주소를 그대로 붙여 넣습니다.

    https://mcp.gomdori.app/law

    주소 뒤에 별도 키 파라미터를 덧붙이지 않고, API 키 입력란도 비워 둡니다.

  6. 저장한 뒤 새 대화의 도구/앱 목록에서 법령 MCP를 선택합니다.

법령 MCP 연결 확인

연결 메뉴가 없을 때

커넥터 생성 권한은 계정·요금제·조직 관리자 설정에 따라 달라질 수 있습니다. 이때 설치를 억지로 진행하지 말고, 강사가 미리 연결한 도구로 같은 프롬프트를 실행하며 결과 검증 과정을 관찰합니다.

법령 결과를 다루는 안전수칙

  • AI의 답변은 법률 자문이나 최종 판단이 아니라 검색·정리 보조 결과로 취급합니다.
  • 법령명·조문·시행일·부칙은 공식 원문과 대조합니다. 필요하면 국가법령정보센터에서 다시 확인합니다.
  • 기관 내부 문서, 개인정보, 미공개 특허정보를 연결된 도구에 붙여 넣지 않습니다.
  • 조회일과 원문 링크를 기록하고, 초안 문장과 근거 문장을 구분합니다.

시연에서 볼 다섯 장면

  1. 사람이 자연어로 조사 목적을 말합니다.
  2. AI가 필요한 검색 도구와 조건을 고릅니다.
  3. 도구가 공개 특허정보를 반환합니다.
  4. AI가 표와 보고서 초안을 만듭니다.
  5. 사람이 노이즈·상태·근거를 다시 확인합니다.
